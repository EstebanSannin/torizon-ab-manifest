Torizon OS — A/B builds OSTree-free

Community builds of the dual-rootfs A/B Torizon OS variant with two updater backends — RAUC and SWUpdate — delivered over Torizon Cloud (aktualizr generic secondary). No OSTree.

Build it yourself

One command gets you a reproducible tree pinned to the tested revisions:

repo init -u https://github.com/EstebanSannin/torizon-ab-manifest -b main \
          -m torizon-ab/tdx/release.xml
repo sync
# then: source setup-environment build, DISTRO=torizon-ab | torizon-ab-rauc, bitbake

Flashing

x86 (.wic): decompress and write to the target disk.

xz -d torizon-minimal-ab-*.wic.xz
sudo bmaptool copy --bmap torizon-minimal-ab-*.wic.bmap torizon-minimal-ab-*.wic /dev/sdX
# (or: sudo dd if=torizon-minimal-ab-*.wic of=/dev/sdX bs=4M status=progress)

Updating over the air

Provision the device to Torizon Cloud, then push the payload (.raucb for RAUC, .swu for SWUpdate) as a package for the <machine>-rootfs secondary. Verify every download against SHA256SUMS.

Built automatically from EstebanSannin/torizon-ab-manifest. Development signing keys — not for production.
